# Facturae library

This repo is a fork from [totaler/facturae](https://github.com/totaler/facturae) with support for Facturae 3.2.2 and utilities extensions.

Originally it allows you to build Facturae xml format based on v3.2.2

It depends on [libComXML](https://github.com/gisce/libComXML)

## Install

```
$ pip install facturae
```
